豆包影视盒 v1.0.0 —— 使用说明
================================================================

一、这是什么
  一个纯本地 Windows 桌面程序（Electron 打包的便携版，不是网页）。
  它汇总多个公共影视采集站（Apple CMS 接口）的片源，输入片名即可在所有源里并发搜索，
  并在程序内部直接播放 m3u8 视频流，不用打开浏览器、不用装播放器。

二、怎么启动
  双击桌面上的「豆包影视盒」快捷方式即可。
  或直接双击 D:\DoubaoTV\electron.exe（不要改名，它就是这个程序的主程序）。

三、功能
  1. 搜索
     - 输入片名回车，所有启用的片源并发搜索，结果显示速度与命中条数。
     - 结果按影片合并：一张卡片代表一部片，角标「N 源」表示几个源都有这片。
     - 点卡片进入详情：可切换片源、切换播放线路、选集播放。
     - 「深度搜索」会对每个源多翻 3 页，结果更全但慢一些。
  2. 分类浏览
     - 按片源自己的分类（动作片 / 剧集 / 动漫 / 综艺…）翻页浏览。
  3. 我的收藏
     - 详情页点「★ 收藏」，收藏页点卡片会重新搜索该片。
  4. 片源管理
     - 内置 9 个实测可搜索的采集站，可停用、删除、新增。
     - 「测速」会真的搜一次关键词，返回耗时和条数，能确认接口是否还活着。
     - 支持「导出配置」到剪贴板/文本框，也支持批量导入（每行「名称 地址」或 JSON 数组）。
     - 新源要求：形如 https://xxx.com/api.php/provide/vod 的 MacCMS 采集接口，且支持 wd 搜索参数。
  5. 播放器
     - 快捷键：空格 播放/暂停，← → 快退/快进 10 秒，↑ ↓ 音量，F 全屏，Esc 退出。
     - 支持倍速（1x / 1.25x / 1.5x / 2x / 0.75x）。
     - 遇到「分享页」形式的线路（形如 https://xxx/share/xxxx），程序会自动解析出真正的 m3u8 地址。
     - 某条线路打不开时，会自动换到这部片的其它线路、其它片源，全部试完才提示「片源线路失效」。
     - 控制条右侧有一个分辨率徽标（如 1920×800），显示的是**实际解码出来的**分辨率（源站 m3u8 里写的分辨率经常不准）。
       默认锁定「最高档」：只要片源提供多档，就固定用码率最高那档，不会因为窗口大小或带宽估算自动降档。
       点这个徽标可在「锁定最高」和「自动升降档」之间切换（锁定最高时按钮是琥珀色）。网络吃紧、卡顿频繁时切回自动更稳。
     - 控制条上还有一个「原始 / 铺满」按钮，控制**画面显示尺寸**：
       「原始」（默认）＝画面最多按片源真实分辨率显示，一个视频像素对应一个屏幕像素，绝不放大；
       低分辨率片源（720p 之类）放在大窗口里被拉大才会发虚，这个模式从根上避免这件事。片源比窗口大时会自动等比缩小到窗口内。
       「铺满」＝画面尽量填满窗口，小片源会被放大，看起来"大但糊"。想看清楚细节就用「原始」。
     - 软件窗口本身也可以在界面里用 Ctrl + 加号 / Ctrl + 减号 整体缩放（Ctrl 0 复位 100%），设置会被记住。
       窗口大小和位置也会记住，下次打开还是你上次调的样子。
       ⚠ 画质上限由片源决定：源站只编码了一档（实测多数采集源就是单档），程序无法凭空生成更高分辨率。
       想看更高清，办法是换一条标了 HD 的线路或换一个片源（不同源同一部片清晰度常不同）。
  6. 启动自动更新片源（默认开启，全程后台）
     - 更新在主进程后台异步执行，不占界面、不重建窗口：正在播放的视频不会被关闭、暂停或跳页。
     - 时间点：启动后约 3 秒跑一次；之后程序运行期间每 6 小时静默刷新一次。
     - 每次启动会自动做一次片源体检：并发访问每个启用源的分类接口，统计「N 个源几个可用」，
       结果显示在「片源管理」页的「上次更新」一行，详细结果（每个源的耗时/错误）记录在 data\app-config.json。
     - 若在「片源管理」里填了「片源订阅地址」，后台更新还会拉取该地址的片源列表并与本地合并
       （自动去重、保留你原有源的启用状态，只增不减）。
       订阅内容支持：JSON 数组 [{"name":"…","url":"…"}]、{sites:[…]}，或每行一条「名称 https://…」。
     - 播放中更新完成不会弹窗打扰，只在「搜索」页提示一行状态；「片源管理」里点「立即更新片源」可手动跑一次。
  7. 伦理片（启动默认打开）
     - 侧边栏「伦理片」页会跨所有启用源，抓取各站自身的「伦理片」分类（各站分类 ID 不同，程序按分类名匹配）
       并按影片合并，支持翻页。
     - 每次启动自动打开该页，可在「片源管理」里用「启动时自动打开『伦理片』」关掉。
     - 该分类内容来自第三方站点，题材由源站分类决定，与程序无关；不喜欢可关掉这个启动行为。
  8. 手机（iPhone）访问
     - 程序启动时会在本机开一个只服务局域网的网页入口，地址显示在「使用说明」页顶部（带「复制」按钮），
       形如 http://192.168.x.x:8899 。手机连同一个 WiFi，用 Safari 打开这个地址即可用。
     - 手机上能做什么：搜片名、点海报看详情、切换片源/线路、选集、全屏播放（横过来就是全屏）。
     - 原理：采集站的 CDN 要校验 Referer、分片又跨域，iPhone 原生播放器直连必失败。
       所以由电脑侧把 m3u8 清单读出来，把里面每个子清单/分片/密钥地址改写成「本机 /p?u=…」，
       手机全程只跟电脑通信，电脑负责带上正确的 Referer 去取真实流。手机和电脑必须都开着，电脑关掉就播不了。
     - 端口：默认 8899。被占用时自动往后试（8898…），实际地址以界面显示为准。
       想改端口或关掉这个入口，编辑 data\app-config.json 里的 lanPort / lanEnabled（false 即关闭）。
     - 打不开时按顺序排查：
       1) 手机和电脑是不是同一个 WiFi（不要一个连 5G 一个连访客网络）；
       2) 电脑 IP 变了（重启路由器常见）——以界面显示的最新地址为准，别用旧地址；
       3) Windows 防火墙拦了：第一次启动若弹「是否允许访问网络」点「允许」；
          或手动放行该端口：控制面板→系统和安全→Windows Defender 防火墙→高级设置→入站规则→新建规则→端口→TCP 8899；
       4) 路由器开了「AP 隔离/访客网络隔离」，同 WiFi 下设备互不可见，关掉它或把电脑和手机接到同一普通网络。
     - 安全边界：这个服务只监听局域网，不做端口映射就不会暴露到公网；不在局域网里别人碰不到。
  9. 下载到本地（离线看）
     - 详情页里每集右上角有个「⤓」，点它把这一集下到本地；「⤓ 下载整条线路」按钮把当前片源/线路的所有集排队下载。
     - 文件存到 D:\DoubaoTV\downloads（可在 data\app-config.json 用 downloadDir 改路径），命名是「片名 - 集名.ts」。
     - 下载在后台跑，进度显示在右下角「下载任务」浮层：已下/总片数、已下体积、实时速度；可随时「取消」。
       「打开文件夹」直接定位到下载目录。整条线路下载是一集接一集排队执行，不会几十个连接一起抢带宽。
     - 原理：HLS 线路本质是几百到上千个小分片，程序按清单顺序把分片抓下来（有 AES-128 加密的线路会先取密钥解密），
       边抓边按顺序拼成一个文件，抓完就是可离线播放的成品，不是半截残片。
     - 体积与耗时：取决于片源码率。实测整部电影（量子源，2618 个分片）下下来 1.85 GB、用了 611 秒（约 3.2 MB/s）；
       换片源或换线路速度可能差好几倍。开始前建议先看一眼剩余磁盘空间。
     - 下载出来的 .ts 是标准 MPEG-TS，VLC、PotPlayer、mpv 都能直接播；Windows 自带的「电影和电视」认不出 .ts，
       想看顺手就装个 PotPlayer，或事后用 ffmpeg 转 mp4（`ffmpeg -i a.ts -c copy a.mp4`，程序本身不带 ffmpeg）。
       .mp4 结尾的是 fMP4（EXT-X-MAP）线路，多数播放器直接认。
     - 下载过程中关掉程序或断网会中断，未完成的半截文件会被自动删掉，不会留下一个看着像成功的坏文件。
     - 手机端不提供下载（只在线播放）；要下的片请在电脑上操作。
       介意的话把 lanEnabled 改成 false，功能依然只有桌面版。

四、文件都放在哪
  所有文件都在 D:\DoubaoTV，不在 C 盘留任何东西，也不写注册表、不装系统服务。
    electron.exe / *.dll     程序本体（Electron 运行时）
    resources\app\           程序界面与逻辑（main.js、preload.js、downloader.js、lan-server.js、ui\）
    app.ico                  图标
    downloads\               下载到本地的影片（默认放这里，可删）
    data\                    你的数据（全部可删，重建后是默认状态）
      sources.json           片源列表
      app-config.json        启动设置与片源体检结果（自动更新开关、订阅地址、每个源的可用性、
                             手机入口开关 lanEnabled 与端口 lanPort）
      favorites.json         收藏
      history.json           搜索历史
      logs\app.log           运行日志（出问题时看这个）
      其余文件夹是浏览器缓存，不用管
  彻底卸载：删掉 D:\DoubaoTV 整个文件夹 + 桌面快捷方式即可。

五、常见问题
  Q: 搜索有结果但点开某条线路播不了？
  A: 采集站的线路经常失效（CDN 节点下线时，该线路会直接返回 404）。程序已做自动处理：
     当前线路打不开时会自动换到这部片的其它线路、其它片源；全部试完才给出「片源线路失效」提示。
     这时点「用浏览器打开」可验证是不是源站自己挂了，通常换一部片子或换个片源就能看。
     技术上：判断依据是线路地址/播放页是否返回 404，以及播放器连续两次加载失败后不再死循环重试。

  Q: 某个源突然都搜不到东西？
  A: 到「片源管理」点它的「测速」，若报超时/403，说明该源已失效，删除或换新接口。

  Q: 播放卡顿？
  A: 多数是片源 CDN 限速，换片源比换播放器有效。也可以先暂停 10 秒让缓冲区攒起来。

  Q: 视频画面黑屏只有声音？
  A: 极少见，通常是该片源编码特殊，换线路或用浏览器打开验证。

  Q: 能手机看吗？
  A: 能。程序内置局域网入口，地址在「使用说明」页顶部（如 http://192.168.1.233:8899）。
     手机连同一个 WiFi，Safari 打开这个地址即可搜索、选线路、在线播放。电脑要开着。
     详见上文「三、功能 → 8. 手机（iPhone）访问」。

  Q: 手机打开是空白/转圈打不开？
  A: 九成是网络层问题，不是软件坏了：确认同一个 WiFi、用界面显示的最新 IP（重启路由器会变）、
     防火墙允许该程序访问网络；路由器若开了 AP 隔离/访客网络，同 WiFi 设备之间也互相访问不了。

  Q: 下载很慢或下载失败？
  A: 慢是源站 CDN 限速，换一个片源/线路再下往往快好几倍（不同源走不同 CDN）。
     失败常见原因：该线路的分片已 404（源站下线）、清单是直播型（没有结尾）、磁盘满了。
     失败时右下角会写明原因，半截文件会被自动删掉，重新下载即可。

六、免责说明
  本程序不存储、不分发任何影视文件，只向第三方公开采集接口发起检索请求并转发播放地址，
  资源内容与可用性由各第三方站点负责。下载功能只是把你自己正在观看的流按顺序存成本地文件，供个人离线观看，
  请勿再分发或用于商业用途。请遵守当地法律法规，仅用于个人学习与测试。
