使用说明

手机连同一个 WiFi，用 Safari 打开上面的地址即可搜索、选线路、在线播放（播放由本机代理转发，画面与电脑端同源）。

这是什么：一个纯本地桌面程序，汇总多个公共采集站（CMS 接口）的片源，输入片名即可全网搜索，并在程序内直接播放 m3u8 视频流。

基本操作

  • 在「搜索」页输入片名回车，结果会按影片合并，卡片上标出该片在几个片源里有（点开可切换线路、选集）。
  • 播放器控制条右侧的分辨率徽标（如 1920×800）显示实际解码分辨率；默认锁定最高档，点击可切「锁定最高 / 自动升降档」。
  • 旁边的「原始 / 铺满」按钮控制画面尺寸：「原始」（默认）按片源真实分辨率显示、绝不放大（一个视频像素对一个屏幕像素，最清晰）；「铺满」尽量填满窗口，小片源会被放大变糊。
  • 窗口大小和位置会被记住；界面整体缩放用 Ctrl + / Ctrl -（Ctrl 0 复位），设置同样会记住。
  • 详情页每集右上角「⤓」= 下载这一集到本地；「⤓ 下载整条线路」= 把当前线路所有集排队下载。文件存到 D:\DoubaoTV\downloads，右下角浮层显示进度、速度，可取消。下来的 .ts 用 PotPlayer / VLC 播。
  • 「分类浏览」按片源自身的分类（电影 / 剧集 / 动漫 / 综艺…）翻页看片。
  • 「伦理片」页跨所有片源抓取各站的「伦理片」分类并按影片合并，支持翻页；启动时默认自动打开。
  • 每次启动会在后台自动做一次片源体检（约 3 秒后开始，之后每 6 小时一次），不占界面、不打断正在播放的视频；可在「片源管理」查看上次结果、填订阅地址或关掉该行为。
  • 「片源管理」可增删改，内置 9 个已验证可搜索的源；源失效时删掉或替换即可。
  • 播放器快捷键：空格 播放/暂停、← → 快退/快进 10 秒、↑ ↓ 音量、F 全屏、Esc 退出播放。

说明与边界

  • 所有影片资源均来自第三方采集接口，程序不存储任何片源文件，仅做检索与播放转发。
  • 播放依赖源站线路的可用性；某条线路卡顿时，在详情里换一个片源或换一条播放线路。
  • 程序不写注册表、不装服务，全部数据都在 D:\DoubaoTV\data（片源、收藏、历史、日志）。删掉整个文件夹即彻底卸载。
